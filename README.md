# Index

## [C](https://github.com/spacotto/grimoire/tree/main/C) (`.c`)
**C** is a **general-purpose**, **procedural programming language** created in the early 1970s that operates close to hardware level while maintaining portability across systems. It features manual memory management, static typing, minimal runtime overhead, and direct access to memory through pointers. C compiles to efficient machine code, provides low-level system control without assembly language complexity, and uses a relatively small set of keywords with a straightforward syntax. Its combination of performance, hardware access, and portability made it the foundation for operating systems (notably Unix), embedded systems, and many modern programming languages.

## [Git](https://github.com/spacotto/grimoire/tree/main/git)
**Git** is a free, open-source distributed **version control system** designed to track changes in source code during software development.

## [Markdown](https://github.com/spacotto/grimoire/tree/main/markdown) (`.md`)
**Markdown** is a **lightweight markup language** created in 2004 that uses plain-text formatting syntax to create structured documents that are easy to read and write in their raw form. It converts simple, intuitive symbols (like asterisks for emphasis, hashes for headings, and brackets for links) into formatted HTML output. Markdown prioritises readability in its unformatted state, requires no special software to write or read, and supports basic document elements like headers, lists, code blocks, links, and images. Its simplicity and human-friendly syntax made it widely adopted for documentation, readme files, web content, and note-taking applications.

## [Python](https://github.com/spacotto/grimoire/tree/main/python) (`.py`)
**Python** is a **high-level, interpreted, general-purpose programming language** created in 1991 that emphasises code readability and simplicity through its clean, English-like syntax and significant use of whitespace indentation. It features dynamic typing, automatic memory management, an extensive standard library, and supports multiple programming paradigms, including procedural, object-oriented, and functional programming. Python executes code line by line without requiring compilation, offers interactive development capabilities, and prioritises developer productivity over raw execution speed. Its versatility, beginner-friendly design, and rich ecosystem of third-party packages made it widely adopted across web development, data science, automation, artificial intelligence, and scientific computing.

## [Shell](https://github.com/spacotto/grimoire/tree/main/shell) (`.sh`)
**Shell** is a **command-line scripting language** that provides an interface for interacting with operating systems and automating tasks through text-based commands. It interprets commands interactively or from script files, enabling users to execute programs, manipulate files, manage processes, and chain operations using pipes and redirection. Shell features simple syntax focused on system administration, built-in commands for file and process management, variables and control structures for scripting logic, and the ability to combine small utilities into powerful workflows. Its direct access to system functions, text-processing capabilities, and ubiquity across Unix-like systems made it essential for system automation, deployment scripts, and rapid task execution without compilation.
