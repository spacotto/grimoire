# Code Blocks
## Inline code
```
`code`
```

**Example** 
- `code`

## Block code
**Syntax:** 
``` 
```[ENTER]code[ENTER]```
```

**Example:**
```
code
block
```

## `diff`
```
# You have to add "diff" on the same line of the ``` marking the start of the code block.

diff --text        # Blue
- text             # Red
+ text             # Green
@@ text @@         # Purple
```

**Example:**
```diff
diff --text
- text
+ text
@@ text @@
```
