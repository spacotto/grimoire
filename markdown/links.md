# Links
## Text link
```
[text](url)
```

**Example:**
[text](URL)

>[!TIP]
>You can copy a link, select the text you want to display, and `CTRL+V` while the text is still selected to trigger the correct syntax.

## Image
```
![alt](URL)
```
