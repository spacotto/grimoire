# Lists
## Unordered
```
- item` or `* item
```

**Example:**
- item
- item
- item

### List (ordered)
**Syntax:** 
```
1. item
2. item
3. item
```

**Example:**
1. item
2. item
3. item

### Nested lists
**Syntax:** 
```
- text
  - text
    -text
```

**Example:**
- text
  - text
    - text

### Task Lists (GFM)
**Syntax:** 
```
- [x] Done
- [ ] Not done
```

**Example:**
- [x] Done
- [ ] Not done
