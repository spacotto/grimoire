# Tables
### Table
**Syntax:** 
```
| TEXT | TEXT | TEXT |
| ---- | ---- | ---- |      # Separates the title row from the other rows
| text | text | text |
| text | text | text |
| text | text | text |
```

**Example:**
| TEXT | TEXT | TEXT |
| ---- | ---- | ---- |
| text | text | text |
| text | text | text |
| text | text | text |

>[!TIP]
>You can align the text on the centre ` :---: `, on the left ` :--- `, or on the right ` ---: `.
