# Text Format
## Bold
```
**bold**            # Syntax 1 
__bold__            # Syntax 2
```

**Example:** 
- **bold**
- __bold__

## Italic
```
*italic*            # Syntax 1 
_italic_            # Syntax 2
```

**Example:**
- *italic*
- _italic_

## Bold + Italic
```
***text***
```

**Example:** 
- ***text*** 

## Strikethrough
```
~~text~~
```

**Example:** 
- ~~text~~

==test==
